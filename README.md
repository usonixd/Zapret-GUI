# Zapret Desk

**Zapret Desk** — простая графическая оболочка для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) под Windows.

> **Бета-версия v0.7.** Я разрабатываю только интерфейс и функции управления. Стратегии обхода, `winws` и драйвер WinDivert принадлежат своим авторам.

### Возможности

- Запуск и остановка zapret без работы с BAT-файлами.
- Выбор из **22 стратегий** Flowseal.
- Автоматическая проверка стратегий для Discord и YouTube (результаты ориентировочные, проверяйте сервисы вручную).
- Game Filter с настройкой TCP/UDP-портов.
- Списки доменов, автозапуск и обновление ядра.
- Тёмный интерфейс, подсказки и масштабирование окна.

### Установка

Программа рассчитана на **Windows 10/11 x64**.

1. Скачайте `ZapretDesk-v0.7.exe` из раздела [Releases](../../releases), **когда бета-релиз будет опубликован**.
2. Остановите другие экземпляры zapret / winws.
3. Запустите EXE, выберите стратегию и нажмите кнопку запуска. Для работы драйвера могут понадобиться права администратора.

При первом запуске встроенные файлы ядра извлекаются в `%LOCALAPPDATA%\ZapretDesk`. Там же лежат настройки, отчёты и журналы (`app.log`, `winws.log`).

### Сборка из исходников

Требуется Go 1.22+ и полный исходный пакет v0.7 (включая `core.zip`, `rsrc_amd64.syso` и ресурсы иконки).

```powershell
go test ./...
$env:GOOS = "windows"
$env:GOARCH = "amd64"
go build -trimpath -ldflags "-H=windowsgui -s -w" -o ZapretDesk-v0.7.exe .
```

### Баги и обратная связь

Можно сообщить о проблемах через [Issues](../../issues). Особенно полезны версия Windows, шаги воспроизведения и скриншот. **Не публикуйте конфиденциальные данные и личные сведения из логов.**

### Ограничения

- Статус `winws.exe` не гарантирует доступность Discord/YouTube.
- Автоподбор не измеряет пинг голосового UDP в Discord или реальную скорость видеопотока YouTube.
- Приложение **не подписано** цифровым сертификатом; Windows может показать предупреждение.
- Бета-сборка v0.7 требует дополнительной проверки интерфейса и сетевой работы на настоящей Windows.
